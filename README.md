Official implementation of HERA (Heterogeneity-Exploiting Representation and Adaptive interaction) for Optical-SAR Remote Sensing Object Detection.

HERA addresses cross-modal heterogeneity from both the representation and interaction perspectives through modality-specific structure-guided detail enhancement (MSDE) and reliability-guided dual-path local cross-modal interaction (RDLCI).

The source code and trained models are being organized and will be made publicly available upon acceptance of the paper.
