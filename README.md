# HERA

Official repository for **HERA (Heterogeneity-Exploiting Representation
and Adaptive interaction)** for optical–SAR remote sensing object detection.

HERA addresses cross-modal heterogeneity from both the representation
and interaction perspectives through modality-specific structure-guided
detail enhancement (MSDE) and reliability-guided dual-path local
cross-modal interaction (RDLCI).

## Implementation

This project is developed based on the official
[M4-SAR code repository](https://github.com/wchao0601/M4-SAR).

## Release Status

This repository currently contains a partial code release.
The core implementations of MSDE and RDLCI are not yet included,
and the current release does not support full reproduction of HERA.

The complete implementation and trained models will be released
upon acceptance of the paper.
